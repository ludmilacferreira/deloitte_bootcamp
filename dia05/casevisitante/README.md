O case resolvido tem como objetivo cadastrar, listar, buscar, ordernar e registrar a saída dos visitantes de um coworking.
Foi utilizado o try/catch para definir as condicionais de opções do menu e o switch/case para escolha de cada uma das opções, onde cada "case" é uma opção do menu que ao ser escolhida, uma ação (método) é chamada. O catch exibe uma mensagem de erro caso haja alguma incoerência dos dados com a pesquisa, ex: usuário tenta buscar a lista de visitantes, porém não existe nenhum visitante cadastrado. Foram criados métodos para cada ação dentro do menu. Foi criada uma classe para a gestão dos dados em memória, ela permite adicionar novos visitantes, listar os cadastrados e também filtrar por pesquisa se o visistante está indo no coworking pela primeira vez ou não. Foi criada uma classe para declarar a variáveis: Nome; Documento; Horario de Chegada; Se é a primeira vez no coworking e o Horário de Saída.
